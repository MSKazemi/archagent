# Support

ArchAgent is maintained by one person in their own time. Here is the fastest route for each
kind of question.

| I want to… | Go to |
|---|---|
| Understand what it does and how to start | [README.md](README.md) |
| Deploy it on a server | [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) |
| Report a bug | [Open an issue](https://github.com/MSKazemi/archagent/issues/new/choose) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md) — **not** a public issue |
| Correct the legal/procurement logic | Open an issue with the article citation |
| Propose a feature | [Open an issue](https://github.com/MSKazemi/archagent/issues/new/choose) |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |
| See what is planned | [ROADMAP.md](ROADMAP.md) |

## Before you open an issue

Include your Python version (`python3 --version`), your OS, the exact command you ran, and the
full output. For anything involving the API, include the request and the response body — the
`X-Request-Id` header on error responses helps a lot.

## Response expectations

This is a single-maintainer, early-stage project with no support guarantee. Issues are read,
but a reply may take a week or more. Pull requests that come with tests are handled fastest.

## What this project cannot help with

- Legal or compliance advice on a specific tender. ArchAgent encodes public rules with
  citations; it does not replace a lawyer or a qualified bid consultant.
- Guaranteeing completeness of tender coverage for a given market.
- Operating your instance, your data, or your GDPR obligations as a controller.
